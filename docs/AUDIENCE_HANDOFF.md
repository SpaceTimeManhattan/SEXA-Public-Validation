# Australia Audience Handoff

## Run SEXA yourself

1. Go to **SEXATech.com/validate**.
2. Click **VIEW / DOWNLOAD PUBLIC AUDIT ON GITHUB**.
3. On GitHub, click **Code → Download ZIP**, or download the latest Release.
4. Unzip the folder.
5. Windows: double-click `RUN_WINDOWS.bat`.
6. macOS/Linux: run `bash RUN_MAC_LINUX.sh`.
7. Read `reports/MASTER_AUDIT_REPORT.md`.

No NumPy, SciPy, Jupyter, compiler, or special scientific package is required.

### What the result means
A PASS means the exact coded target reproduced. Claims requiring unavailable raw data, future hardware, or physical experiments are labeled separately instead of being counted as computational PASSes.
